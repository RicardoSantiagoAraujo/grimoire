# ANGULAR APP: Grimore

## Pre-requisited:
- node.js;
- For MacOS: MAMP;
- Eclipse IDE;


## Installation and set-up:
### Back-end
1. Run MAMP with Apache server;
2. Check if phpMyAdmin is working correctly;
3. In Eclipse, run "MythikApplication.java";

### Front-end
1. Install packages

```
npm install
```
2. Run angular
```
ng serve --open
```
